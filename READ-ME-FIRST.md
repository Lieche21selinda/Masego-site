# GitHub upload — flat version

Every file sits at the top level. No subfolders, and index.html points at the images
directly, so the flattening problem that broke the images cannot happen again.

1. Unzip this file.
2. Go to https://github.com/lieche21selinda/masego-website-NWU
3. Delete everything currently there (Settings → bottom → Delete this repository is
   quickest, then create a new one with the same name).
4. Add file → Upload files → drag in all the files → Commit changes.
5. Settings → Pages → Branch: main, Folder: / (root) → Save. Wait a few minutes.

Nothing should be inside a folder when you are done.

Note: two video files are included (about 19 MB together), so the upload takes
longer than before. GitHub handles files this size without complaint.
